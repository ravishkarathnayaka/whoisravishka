# Who is Ravishka — Personal Portfolio Website

An editorial, high-performance cyberpunk personal portfolio built for **Ravishka Rathnayaka** (Cybersecurity Specialist · MLOps & DevOps Engineer · Videographer).

Inspired by the design language, telemetry, and interactive architecture of **[whoislsam.com](https://whoislsam.com/)**.

---

## ⚡ Key Highlights & Features

- **Cyber-Editorial Typography & Visuals**:
  - `Playfair Display` luxury display serifs mixed with italic highlights
  - `DM Mono` for cyber telemetry, terminal commands, and system status
  - `Manrope` for clean, modern readability
  - Obsidian ink (`#060709`) with electric orange/ember accents (`#ff4d00`)
  - Ambient film-grain noise texture & interactive radial cursor spotlight

- **Hero & Command Telemetry**:
  - Giant split typographic heading (`RAVISHKA` in solid white, `RATHNAYAKA` in stroked outline)
  - Orbital glowing rings & live telemetry widgets (Defensive Posture: RESILIENT, Pipeline Health: 99.9%)
  - Continuous signal marquee ticker ribbon

- **Editorial Manifesto & Identity Portrait**:
  - Polygon-clipped portrait frame with animated laser scanning beam
  - Operating principle narrative & 4 animated metric counters (Years in Tech, Projects, Credentials, Community Events)
  - Direct social channel integration (LinkedIn, GitHub, Medium, Instagram)

- **SOC & DevOps 24×7 Operations Console**:
  - Live animated 360° radar sweep with pulsing target blips
  - Core capability breakdown: Alert Triage, CI/CD Hardening, MLOps Orchestration, Production Reliability
  - Interactive tool stream elevation badges

- **Live Threat & DevOps Intelligence Observatory**:
  - Interactive SVG world sensor map with country centroid pins and regional inspector
  - Actively Exploited CVE feed (CISA KEV) with CVSS scores and summaries
  - Live cyber threat headlines & real-time telemetry metrics

- **Interactive Capability Constellation Graph**:
  - Interconnected SVG node network (Cyber Defense, Kubernetes, Docker, MLOps, Cloud, CI/CD, Linux, Dev)
  - Click-to-inspect dynamic operational intel panel

- **Verified Credentials Vault**:
  - Searchable credential register with `⌘K` / `Ctrl+K` keyboard shortcut
  - Category filters (Security, Cloud/DevOps, AI/Data, Academic)
  - Credly and official verification links

- **Project Archive ("Work from the Front Line")**:
  - Technical domain filters: Cybersecurity, DevOps/Cloud, MLOps/AI, Media
  - Interactive inspection modals with architectural highlights and source links

- **Writing & Field Notes ("Thinking in Public")**:
  - Integration with published guides on Ollama AI models, Git history troubleshooting, and software practices

- **Field Log & Journey Timeline**:
  - Chronological timeline covering Metadew Technologies, Fiverr, and First Class Honours at SLTC

- **Community & Leadership Showcase**:
  - Highlighting roles as Founding Chairperson of CloudSpace v1.0, Chairperson for Codemania V6.0 Datathon, and IEEE SLTC

- **Contact Terminal ("Let's Build the Unbreakable")**:
  - High-impact electric orange contact section with radar signal rings, direct email copy button, and secure message form

- **Embedded AI Portfolio Terminal Assistant (`whoisravishka AI`)**:
  - Floating pulsing trigger button opening a real-time portfolio assistant drawer
  - Supports natural questions and slash commands (`/help`, `/skills`, `/projects`, `/cloudspace`, `/experience`, `/contact`)

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom Keyframe Animations (`radarSweep`, `laserScan`, `orbit`, `marquee`)
- **Icons**: Lucide React
- **Typography**: Google Fonts (`Playfair Display`, `DM Mono`, `Manrope`)

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
```
The optimized, static output will be generated in the `dist/` directory, ready to deploy to GitHub Pages, Vercel, Netlify, or Cloudflare Pages.

### 4. Preview Production Build Locally
```bash
npm run preview
```
